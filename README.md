# Jane Zhang Personal Website (2019)

A personal website with **Django**, designed to showcase my profile, projects, and activities. The site serves as both a personal portfolio and a content hub, featuring sections for my **CV**, **blog**, and **interactions**.

> 🛠️ **Note:** This project was created as a learning and personal portfolio site.  
> It is currently **not deployed online**.
---

## 🌐 Overview

This project was my first full-stack web application, built from scratch while learning Django and web development fundamentals. It combines several Django apps into a cohesive personal site.

**Key apps included:**
- **cv/** – Displays personal and professional background.
- **blog/** – Manages and displays blog posts.
- **interaction/** – Handles user interactions or contact forms.
- **media/** – Stores uploaded media and profile images.
- **Templates/** – Shared HTML templates for rendering pages.

---

## 🧰 Tech Stack

- **Framework:** Django (Python 3.8)
- **Database:** SQLite3 (default Django DB)
- **Frontend:** HTML5, CSS3, Bootstrap (within templates)
- **Version Control:** Git / GitHub
